# Support

Thanks for using **GitHub Copilot Metrics Dashboard**. This is an open-source, self-hosted
project maintained on a best-effort basis.

## How to get help

- **Setup & usage questions** — read the [README](./README.md) quickstart (demo mode needs no
  GitHub credentials), the [`docs/`](./docs/) runbooks, and the [`specs/`](./specs/) design docs.
- **Bugs** — open a [Bug report](./.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature ideas** — open a [Feature request](./.github/ISSUE_TEMPLATE/feature_request.yml).
- **Documentation gaps** — open a [Documentation issue](./.github/ISSUE_TEMPLATE/documentation.yml).
- **Security vulnerabilities** — do **not** open a public issue. Follow [SECURITY.md](./SECURITY.md)
  (private vulnerability reporting / draft security advisory).

## Before filing an issue

1. Reproduce against the latest release and the demo dataset (`pnpm db:seed:demo`) where possible.
2. Search existing issues to avoid duplicates.
3. Include your version, deployment mode (local / Azure), and relevant non-sensitive logs.

## Support boundaries

This project is provided as-is under the [MIT License](./LICENSE). Response times are best-effort
and there is no commercial support SLA. Production self-hosting readiness is gated by
[`specs/08-launch-readiness-and-priorities.md`](./specs/08-launch-readiness-and-priorities.md).
